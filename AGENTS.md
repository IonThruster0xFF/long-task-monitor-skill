# Installation tasks

When the user asks to install this skill, follow the installation steps in README.md. Identify the actual harness's skills directory; a model name alone does not determine it. Use install.py and preserve existing skills and configuration.

Installation, configuration, repository development and testing do not authorize task reporting. Do not send status or test events during installation. Apply the reporting gate in skills/long-task-monitor/SKILL.md only for a current goal task or an explicit request to report; an explicit no-report instruction takes precedence.
